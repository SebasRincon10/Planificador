    # Gestor de Tareas
    Una aplicación web interactiva y visualmente atractiva diseñada para la organización y gestión eficiente de tareas diarias y semanales. La interfaz combina la estética retro de notas adhesivas (*post-its*) manuscritas con la potencia de las tecnologías web modernas.
